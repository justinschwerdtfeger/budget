# BursaBudget

BursaBudget is a free and open-source personal finance management application built with Next.js and Material UI. It allows users to track their income, expenses, and transfers, and provides a simple and intuitive interface for managing their finances.

[Try it out](https://budget-eight-iota.vercel.app/)
